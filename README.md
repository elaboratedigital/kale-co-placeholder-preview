# The Kale Company — placeholder preview

This is a **working placeholder** of the basic ordering website for The Kale Company (Baltimore, MD). It is not a live restaurant site and is not taking real orders.

The banner on every page says **PREVIEW – placeholder content**. Menu items, prices, hours, address, phone, and email are fake samples so the layout can be reviewed. A preview password is required to view the site; ask David for access.

## What’s in this preview

- Home, About, Hours & Location, Contact
- Menu browsing by category
- Cart (stored in the browser)
- Checkout with pickup or one standard delivery area and a flat delivery fee
- Pay with card (Stripe Checkout integration point, no real keys) or pay at pickup
- All editable content lives in `content.json`

Grill Hearty’s is not part of this site.

Search engines: `robots.txt` and a `noindex,nofollow` meta tag are included on purpose.
